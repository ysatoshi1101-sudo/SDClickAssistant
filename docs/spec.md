## 第1章　概要・権限・基本の流れ

### 1-1. アプリの概要

| 項目 | 内容 |
|---|---|
| 表示名 | ゴーストタッチ |
| 内部プロジェクト名 | SD Click Assistant |
| パッケージ名 | `com.example.sdclickassistant` |
| 種類 | Androidのマクロ自動化アプリ |
| 対象OS | Android 8.0（API 26）以上。compileSdk / targetSdk は 35 |
| 動作確認の実機 | OPPO Reno11 A |
| 対応CPU | `arm64-v8a` のみ（OpenCVの同梱の都合） |

登録した操作の並び（シナリオ）を、Accessibility Serviceを使って、他のアプリの画面上で自動実行する。

### 1-2. 用語

| 用語 | 意味 |
|---|---|
| シナリオ | 複数のステップをまとめたもの。名前、繰り返し回数、実行速度、お気に入り、フォルダを持つ |
| ステップ | 1つの操作や制御。種別は 1-3 を参照 |
| ラベル | ジャンプ先の目印となるステップ |
| テンプレート | 画像認識で探す、画面の一部を切り出した画像 |
| マーカー | 配置待機の画面で、ステップの位置を示す丸い目印 |

### 1-3. ステップの種別

| 種別 | 内容 |
|---|---|
| タップ | 指定した座標をタップ |
| 長押し | 指定した座標を、指定した時間だけ押す |
| スワイプ | 始点から終点まで、指定した時間でなぞる |
| 待機 | 指定した時間（ms）だけ待つ |
| スクリーンショット | 画面を撮影し、端末の `Pictures/SD Click Assistant/` に保存する |
| ラベル | 目印。実行時は何もせず次へ進む |
| ジャンプ | 指定したラベルへ移動する |
| 条件分岐 | 条件に応じて、指定したラベルへ移動する。判定方式は、ループ回数・色判定・画像認識 |

各ステップの詳細は、第3章で記す。

### 1-4. 必要な権限

| 権限・機能 | 用途 | 備考 |
|---|---|---|
| ユーザー補助（Accessibility Service） | タップ・長押し・スワイプの実行 | ユーザーが設定でオンにする。アプリの更新後にグレーで押せなくなる場合がある（Android 13以降の「制限付きの設定」） |
| 他のアプリの上に重ねて表示（SYSTEM_ALERT_WINDOW） | 配置待機・実行中・記録中などのオーバーレイ表示 | 設定で許可する |
| 画面キャプチャ（MediaProjection） | スクリーンショット、色判定、画像認識、スポイト、テンプレート作成 | 該当するステップがある場合のみ必要。許可の取得後は、フォアグラウンドサービスが待機する |
| 通知（POST_NOTIFICATIONS） | 画面キャプチャ中のフォアグラウンドサービスの通知 | |
| フォアグラウンドサービス（メディアプロジェクション型） | 画面キャプチャの維持 | |

- 画面キャプチャが必要かどうかは、ステップの内容から自動で判定する（スクリーンショット、色判定、画像認識が対象）。
- アクセシビリティの `canRetrieveWindowContent` は無効。画面の要素は読み取らない。
- 現在の動作：画面のキャプチャは、色判定・画像認識・スポイト・テンプレート作成のために端末内でのみ使い、外部へ送信する処理はない。スクリーンショットのステップだけが、画像を端末内（`Pictures/SD Click Assistant/`）に保存する。
- プライバシーに関する方針（画面の内容の扱いを、仕様として明記するか）は、**未決定**。

### 1-5. 基本の流れ（安全に実行するための3つの画面）

このアプリは、実行前に必ず確認と配置の段階を挟む。
① 実行前確認画面
↓
② 配置待機画面
↓
③ マクロ実行画面
↓（停止、または完了）
② 配置待機画面に戻る

| 段階 | 内容 |
|---|---|
| ① 実行前確認画面 | シナリオ名、実行設定（無限ループ、繰り返し回数、実行速度）、ステップ一覧を表示。権限が足りない場合は、案内と許可のボタンを表示 |
| ② 配置待機画面 | 対象アプリへ移動し、ドラッグできる操作ボタン群（戻る・再生・マーカーの表示切替・繰り返し回数）を表示。ここで、実行の開始位置を決める |
| ③ マクロ実行画面 | 停止ボタン、ループ回数、現在のステップを、小さなフローティングパネルで表示 |

- 停止、または完了した後は、必ず②へ戻る。
- ③の停止パネルは、②で再生ボタンを置いた位置に表示される。
- 実行中は、パネル全体のタップで停止できる。

詳細は、第4章で記す。

## 第2章　画面仕様

### 2-1. 画面と遷移
シナリオ一覧 → シナリオ詳細 → 実行前確認

- 詳細画面・実行前確認画面の左上の「戻る」で、1つ前の画面へ戻る。一覧画面に戻るボタンはない。
- 実行前確認の次の「配置待機」「実行」は、アプリの外（他のアプリの上のオーバーレイ）で動く。第4章で記す。

### 2-2. シナリオ一覧画面

| 項目 | 内容 |
|---|---|
| タイトル | 「シナリオ一覧」 |
| 新規作成 | 右下の「＋」→ シナリオ名を入力して「作成」（空白のみは不可。前後の空白は除く） |
| 空の時の表示 | 「まだシナリオがありません」「右下の + ボタンから最初のシナリオを作成できます」 |
| カードのタップ | シナリオ詳細へ |

**フォルダの絞り込み（上部のチップ行）**

- 並び：「すべて」「未分類」、各フォルダ、「＋ フォルダ」。
- タップで絞り込み。フォルダのチップを**長押し**すると、「名前を変更」「削除」の選択が出る。
- フォルダは1階層のみ。フォルダを削除しても、中のシナリオは消えず「未分類」に戻る。削除したフォルダで絞り込み中なら、「すべて」に戻る。
- フォルダを絞り込んだ状態で新規作成すると、そのフォルダに入る。
- フォルダ削除に、確認ダイアログはない。

**シナリオのカード**

| 要素 | 内容 |
|---|---|
| ≡（ドラッグ） | 長押しして上下に動かし、並び替える。**「すべて」で絞り込んでいる時だけ**表示（並び順が、全シナリオ共通の通し番号のため） |
| 名前 | シナリオ名を表示（ステップ数は表示しない） |
| ★／☆ | お気に入りの切り替え（表示のみ。並び順・絞り込みには影響しない） |
| ⋮ メニュー | 名前を変更／コピー／フォルダへ移動／削除 |

- **コピー**：名前に「（コピー）」を付け、一覧の最後に追加。ステップは新しいIDで複製し、画像認識のテンプレート画像も複製する。フォルダ・お気に入りは、複製元と同じ。
- **削除**：確認ダイアログ（「この操作は取り消せません」）。ステップとテンプレート画像も削除する。
- **フォルダへ移動**：「未分類」と各フォルダのラジオボタンから選ぶ。

- 一覧用のデータには、ステップを含めない（軽量にするため）。

### 2-3. シナリオ詳細画面

| 項目 | 内容 |
|---|---|
| タイトル | シナリオ名（読み込み中は「読み込み中...」） |
| 「実行」ボタン | 右上。実行前確認画面へ |
| 「＋」（右下） | ステップの追加（2-4） |
| ステップが無い時 | 「まだステップがありません」と「操作を記録して追加」ボタン |
| ステップがある時 | 一覧の先頭に「操作を記録して追加」ボタン、その下にステップのカード |

**ステップのカード**

- ≡ を長押ししてドラッグし、並び替える（離した時に保存）。
- 種別名と、設定の要約を表示。タップで編集（2-4）。
- ゴミ箱アイコンで削除（確認ダイアログあり）。削除後、順番は詰め直される。
- ラベルを削除する時、そのラベルを指すジャンプ・条件分岐があれば、確認ダイアログに「N個のステップから参照されています。削除すると、実行時にそのステップで停止します」と警告を出す（削除は止めない）。同じ名前のラベルが他に残る場合は、警告しない。
- 新しいステップは、常に末尾に追加される。

**要約の表示**

| 種別 | 表示 |
|---|---|
| タップ | `X:.. Y:.. 待機:..ms` |
| 長押し | `X:.. Y:.. 押下:..ms 待機:..ms` |
| スワイプ | `(始点) → (終点) ..ms` |
| 待機 | `..ms` |
| ラベル／ジャンプ | ラベル名／ジャンプ先 |
| 条件分岐（ループ） | 「ラベル」へ N回（空欄は無限に）繰り返す |
| 条件分岐（色） | `(x,y)の色が(R,G,B)に一致する／しない時「ラベル」へ` |
| 条件分岐（画像） | 画像が見つかった／見つからない時「ラベル」へ（一致度..以上）。設定があれば2行目に「最大N秒待つ」「見つけたら位置をタップ」 |

**操作の記録（「操作を記録して追加」）**

1. ユーザー補助が無効なら、ユーザー補助の設定を開く。
2. 重ね表示の権限が無ければ、その設定を開く。
3. 両方そろっていれば、記録を開始してアプリを背面へ移す。
4. 記録の結果は、既存のステップの**末尾**に追加される。

### 2-4. ステップの追加・編集ダイアログ

- 追加時は、まず種別を選ぶ（タップ／長押し／スワイプ／待機／スクリーンショット／ラベル／ジャンプ／条件分岐）。入力画面の「戻る」で選び直せる。
- 編集時は、種別の選択を飛ばす。**種別は変更できない**。
- 条件が満たされない間は、「追加」「保存」ボタンは押せない。

| 種別 | 入力項目（必須は ● ） |
|---|---|
| タップ | X座標●、Y座標●、待機時間(ms) |
| 長押し | X座標●、Y座標●、押下時間(ms)●、待機時間(ms) |
| スワイプ | 開始X●・Y●、終了X●・Y●、スワイプ時間(ms)●、待機時間(ms) |
| 待機 | 待機時間(ms)● |
| スクリーンショット | 設定なし |
| ラベル | ラベル名●（空白のみは不可） |
| ジャンプ | ジャンプ先ラベル●（既存のラベルから選ぶ） |
| 条件分岐 | ジャンプ先ラベル●、判定方式●（下表） |

- タップ・長押し・スワイプには、「画面から取得」ボタンがある（座標を画面上のタップで取得）。取得にはユーザー補助と重ね表示の権限が必要。
- ジャンプ先ラベルは、同じシナリオにあるラベルの一覧から選ぶ。ラベルが無い時は「先にラベルを追加してください」と表示する。
- 待機時間が空欄のタップ・長押し・スワイプは、実行後に待たない。

**条件分岐の判定方式**

| 方式 | 入力項目 | 範囲・既定 |
|---|---|---|
| ループ回数 | 繰り返し回数 | 1以上。空欄は無限ループ |
| 色判定 | 「スポイトで取得」ボタン、X・Y●、R・G・B●、許容誤差、反転 | 色は0〜255。許容誤差は0〜255、空欄は10。反転オンで「一致しない時にジャンプ」 |
| 画像認識 | テンプレート●、一致度のしきい値、見つかるまで待つ最大秒数、位置のタップ、タップ後の待機時間、反転 | しきい値は0.50〜1.00、空欄は0.90。最大秒数は1〜600、空欄は待たず1回だけ判定。タップ後の待機は、空欄で300ms（「位置のタップ」オンの時のみ入力）。反転オンで「見つからない時にジャンプ」 |

**画像認識のテンプレート**

- 「画面からテンプレートを作成」（作成済みなら「テンプレートを作り直す」）で、画面をキャプチャして範囲を選ぶ。プレビューと画像の大きさ（幅×高さ px）を表示する。
- 作成には、ユーザー補助・重ね表示・画面キャプチャの許可が、順に必要。
- 作成中の画像は一時保存され、「追加／保存」で正式な保存になる。「キャンセル」「戻る」で閉じた時は破棄される。編集中にキャンセルしても、元の画像は残る。

### 2-5. 実行前確認画面

| 項目 | 内容 |
|---|---|
| タイトル | シナリオ名 |
| 実行設定 | 無限ループ（スイッチ）、繰り返し回数（無限ループがオフの時のみ表示。1以上）、実行速度（スライダー、0.1〜5.0倍） |
| ステップ一覧 | 「ステップ一覧（N件）」と、各ステップの種別名のみ |
| 保存 | 実行設定は、変更するたびに、自動で保存される |

**下部の案内とボタン**

| 状態 | 表示 |
|---|---|
| 重ね表示の権限が無い | 「実行にはオーバーレイ表示の権限が必要です」 |
| ユーザー補助が無効 | 「実行にはユーザー補助（アクセシビリティ）で…を有効にする必要があります」 |
| 画面キャプチャが必要で、未許可 | 案内文と「画面キャプチャを許可する」ボタン |
| 常時 | 「配置する（対象アプリに移動します）」ボタン。重ね表示の権限が無い時は「オーバーレイ権限を許可する」 |

- 「配置する」：重ね表示の権限 → ユーザー補助 の順に確認し、足りなければ、それぞれの設定画面を開く。そろっていれば、配置待機を開始し、アプリを背面へ移す。
- 画面キャプチャの許可は、「配置する」の必須条件ではない。必要なステップがあるのに許可が無いまま実行すると、実行の開始時に停止する。

### 2-6. 既知の不具合（第2章の範囲）

| # | 内容 | 原因 | 状態 |
|---|---|---|---|
| 1 | 一覧のカードの「N ステップ」が、実際の数にならない | 一覧用のデータに、ステップが含まれない | ステップ数が不要のため、表示を削除（2026-11-22） |
| 2 | 配置待機でマーカーを動かして保存した後、実行前確認画面で実行設定（無限ループ・回数・速度）を変えると、動かした位置が元に戻る | 実行前確認画面が、開いた時の古いステップごと、シナリオを保存し直す | 修正済み。実行設定の3項目だけを保存する（`updateExecutionSettings`） |
| 3 | 配置待機で変えた繰り返し回数・無限ループが、実行前確認画面に戻っても反映されない（その後の保存で、古い値に上書きされる危険もあった） | 実行前確認画面が、開いた時に1回だけ読み込む | 修正済み。画面が前面に戻るたびに、DBから読み直す |

## 第3章　ステップの実行仕様

第2章は「入力画面」の仕様。この章は「実行したときに何が起きるか」の仕様。

注記：3-3〜3-6は、コードを読んで書いた内容で、**実機での確認は未実施**。実際の動きと違う点が見つかったら、直す。

### 3-1. 実行全体の流れ

**開始時の確認**（満たせない場合は、実行を始めない）

1. シナリオが読み込めない、またはステップが0件の場合は、実行せず配置待機へ戻る。
2. 画面キャプチャが必要なステップがある場合は、画面キャプチャの準備を待つ（最大約5秒）。準備できなければ停止する。
3. 画像認識のテンプレート画像を、すべて先に読み込む。1つでも読み込めなければ、開始せず停止する。
4. 実行パネル（停止ボタン）を表示する。

**実行中**

- ステップは、並び順（上から）に1つずつ実行する。
- シナリオ全体を、「無限ループ」、または「繰り返し回数」だけ繰り返す。最後のステップまで進むと1周。
- 実行パネルの表示：1行目は「∞」または「現在の周 / 回数」、2行目は「S現在のステップ / 総数」。

**終了時**

- 最後の周が終わる、STOPが押される、エラーで停止する、のいずれでも、配置待機の画面へ戻る。
- 読み込んだテンプレート画像は、終了時に必ず解放する。
- 画面キャプチャのセッションは、次回の実行で再利用するため、終了しても維持する。
- 停止の理由は、画面には表示されない（ログのみ）。

### 3-2. 実行速度の倍率

実行前確認画面で設定する倍率（0.1〜5.0倍）は、**時間を倍率で割る**形で効く（2.0倍なら半分の時間）。

| 倍率が効く | 倍率が効かない |
|---|---|
| 長押しの押下時間、スワイプの所要時間 | タップの押下時間（100ms固定） |
| タップ・長押し・スワイプの実行後の待機時間 | スクリーンショットの実行後の待機時間 |
| 待機ステップの待機時間 | 画像認識の「見つかるまで待つ最大秒数」と、判定の間隔（500ms） |
| 画像認識の「位置のタップ」後の待機時間 | 画面キャプチャの待ち時間、ジェスチャーの完了待ち（3秒） |

### 3-3. タップ・長押し・スワイプ・待機

| 種別 | 動作 |
|---|---|
| タップ | 指定した座標を、100msのタップで押す |
| 長押し | 指定した座標を、指定した時間だけ押し続ける |
| スワイプ | 始点から終点まで、直線を、指定した時間でなぞる |
| 待機 | 何もせず、待機時間だけ待つ |

- 実行後に、待機時間だけ待つ（空欄は待たない）。
- ジェスチャーは、ユーザー補助サービスで実行する。3秒以内に完了の通知が来なければ、失敗として扱う。
- 失敗した場合（ジェスチャーの失敗、座標や時間が足りない場合）は、ログを残して**次のステップへ進む**（停止しない）。
- ユーザー補助サービスが無効になっている場合は、停止する。

### 3-4. スクリーンショット

- 画面を撮影し、PNG（品質100）で、端末の `Pictures/SD Click Assistant/シナリオ名/` に保存する。
- ファイル名は「日時_シナリオ名_通し番号.png」。通し番号は、実行全体の通し（(周−1)×ステップ数＋現在のステップ番号）。シナリオ名の使えない文字は「_」に置き換える。
- 撮影した後に、待機時間だけ待つ設定になっているが、現在の編集画面には、スクリーンショットの待機時間の入力欄がない（通常は待たない）。
- 画面が止まっている間は、新しい画面の更新が届かないため、直近の画面を使う。
- 失敗した場合（撮影の失敗、保存の失敗）は、**停止する**。

### 3-5. ラベル・ジャンプ

- **ラベル**：何もしない（目印）。実行時は、次のステップへ進む。
- **ジャンプ**：指定した名前の、**最初の**ラベルへ移動する。前のラベルにも、後のラベルにも移動できる。
- ジャンプ先のラベルが見つからない場合は、停止する。ラベルを削除しても、そのラベルを指すジャンプや条件分岐は、自動では直らない（実行時に停止する）。削除の確認ダイアログで警告を出す（2-3を参照）。
- ジャンプが続いても、アプリが固まらないよう、毎回、処理を譲る。そのため、ジャンプだけのループでも、STOPで止められる。

### 3-6. 条件分岐

すべての判定方式に、ジャンプ先のラベルがある。**条件が成立したらジャンプし、成立しなければ次のステップへ進む。** 色判定・画像認識は、反転をオンにすると、成立・不成立が逆になる。

**ループ回数**

- 設定した回数まで、ラベルへジャンプする。回数に達したら、ジャンプせず、**条件分岐の次のステップへ進む**。
- 空欄は無限（いつまでもジャンプし続ける）。
- 回数は、条件分岐ごとに数える。シナリオ全体が1周するたびに、0に戻る。回数に達して次へ進んだ時にも、0に戻る。
- 数え方の例：回数を3にして「[ラベル] → [タップ] → [条件分岐（ラベルへ3回）]」と並べると、ジャンプは3回で、**タップは合計4回**（最初の1回＋ジャンプ後の3回）実行される。

**色判定**

- 画面を撮影し、指定した座標（画面全体を基準）の色を調べる。R・G・Bの**すべて**が、指定色との差が許容誤差以内なら、成立。許容誤差は、空欄で10。
- 判定できない場合（撮影の失敗、座標が画面の外、設定値が足りない）は、不成立として扱わず、**停止する**（反転ジャンプの誤動作を避けるため。画像認識と同じ扱い）。

**画像認識**

- 画面全体から、テンプレート画像に最も似た場所を探す（OpenCVのテンプレートマッチング、RGB）。一致度が、しきい値以上なら、「見つかった」。しきい値は0.50〜1.00、空欄で0.90。位置は、見つかった領域の中心。
- 「見つかるまで待つ」が空欄なら、1回だけ判定する。設定があれば、判定→500ms待つ、を繰り返し、見つかった時点で終わる。時間切れは「見つからなかった」。待っている間も、STOPで止められる。
- 画面の撮影は、1回あたり3秒を上限に、最大3回まで試す（間に200ms）。
- 「位置のタップ」がオンで、画像が見つかったら、その位置をタップし、待機時間（空欄で300ms）だけ待つ。**反転のオン・オフに関係なく**、見つかったら必ずタップする。
- 判定できない場合は、「見つからなかった」ではなく、**停止する**（反転ジャンプの誤動作を避けるため）。対象は、撮影が3回とも失敗、テンプレートが画面より大きい、一色だけのテンプレート（一致度を計算できない）、照合中のエラー。
- テンプレートを作った時と、画面のサイズが違う場合は、ログに警告を出すだけで、判定は続ける（一致しにくくなる）。
